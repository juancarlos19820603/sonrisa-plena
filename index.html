1

El problema y el objetivo

Giovanny Rodriguez Albarracin

Sonrisa Plena es un consultorio odontológico ficticio de Medellín que agenda por WhatsApp y por teléfono, lo que genera cruces de horario, olvidos e inasistencias. El objetivo del sitio es que el paciente conozca los 8 servicios y los 11 especialistas, agende su cita en tres pasos y luego pueda consultarla o cancelarla, desde el computador o el celular.

Se explican las herramientas: Visual Studio Code, HTML, CSS y JavaScript sin marcos de trabajo, Git y GitHub para las versiones, y GitHub Pages para publicar gratis.

2

Estructura y HTML semántico

Andres Ricardo Vargas Avila

El proyecto tiene tres archivos con responsabilidades separadas: index.html (estructura), styles.css (diseño) y main.js (comportamiento), más la carpeta img con las fotografías.

Se muestran la cabecera del documento (idioma, codificación UTF-8, viewport y fuentes) y las etiquetas semánticas header, nav, main y footer, que ayudan a los lectores de pantalla y a los buscadores. Todo el contenido es propio del consultorio.

3

Navegación y agendamiento

Robinson Arenas Vélez

La función route() lee la dirección después del símbolo # y muestra la vista correspondiente. Luego se agenda una cita en vivo: se elige el servicio y el especialista, se escriben los datos (con validación inmediata, por ejemplo el celular debe empezar por 3) y se confirma.

Al confirmar se genera un código que empieza por SP. En Mis citas se busca la cita por código o documento y se puede cancelar. Como GitHub Pages solo sirve archivos, las citas se guardan en el navegador (localStorage).

4

Diseño, Git y publicación

Juan Carlos Londoño Álvarez

Los colores se definen como variables CSS (azul marino y dorado champán) con contraste que cumple la norma de accesibilidad. El diseño es primero para celular y se amplía con media queries; incluye menú tipo botón, barra inferior y modo oscuro.

Se muestra el flujo de Git (git add, git commit, git push), la publicación en GitHub Pages con HTTPS y el cierre: se usó Claude, una herramienta de inteligencia artificial, como asistente, y el grupo probó y aprobó cada versión.

Política de tratamiento de datos

Proyecto académico ficticio. Texto de ejemplo basado en la Ley 1581 de 2012 (Colombia).

¿Qué datos pedimos?

  • Nombre, documento, teléfono y correo para agendar o responder su mensaje.
  • Servicio, odontólogo, fecha y hora de la cita.

¿Para qué los usamos?

Solo para gestionar su cita y contactarle. No los vendemos ni los compartimos.

¿Dónde quedan guardados?

En este sitio de demostración las citas se guardan solo en el almacenamiento local de su navegador (localStorage). No se envían a ningún servidor.

Sus derechos

Puede conocer, actualizar, rectificar y pedir la supresión de sus datos, y revocar la autorización. Escriba a citas@sonrisaplena.co.
